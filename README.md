# ML Portfolio

A collection of Machine Learning, Deep Learning, Computer Vision, and Natural Language Processing projects developed for practical learning and application.

## Projects

### 1. SaaS Customer Churn Prediction
**Category:** Machine Learning

A machine learning project that predicts customer churn using SaaS customer data. The workflow includes exploratory data analysis, preprocessing, MinMaxScaler feature scaling, K-Nearest Neighbors (KNN) and Random Forest classification, model evaluation, and saving the trained model. A Streamlit application (`app.py`) provides an interface for using the project.

[View Project](https://github.com/Preethipkp/saas-customer-churn-prediction)

### 2. Brain Tumor Classification Using CNN
**Category:** Deep Learning | Computer Vision

A deep learning project using a **custom Convolutional Neural Network (CNN)** to classify brain MRI images into four categories: glioma, meningioma, pituitary tumor, and no tumor.

[View Notebook](Brain-Tumor-Classification/brain_tumor.ipynb)

### 3. Employee Data Analysis Using SQL
**Category:** SQL | Data Analytics

An employee data analysis project using SQL queries to explore employee information, salaries, and departmental statistics.

[View Project](https://github.com/Preethipkp/employee-data-analysis-sql)
